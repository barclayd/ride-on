# Map prototype (MapLibre GL JS)

A browser prototype of the cycle.travel-style map that [the plan](../README.md) ports to the app. It's
the reference implementation: every rule in [`cycle-travel-style.md`](../cycle-travel-style.md) is in
`tools/build-style.mjs`, and the screenshots in [`../screenshots`](../screenshots) were taken from it.

It is **not** production code. Its data comes from Overpass as GeoJSON (33 MB for south-east England),
which is fine in a desktop browser and impossible in the app. WS1 in the plan replaces it with vector tiles.

## What's here

| Path | What it is |
|---|---|
| `index.html` | MapLibre GL JS page. Loads `style.json`, registers the `pmtiles://` protocol, draws the route badges at runtime (`styleimagemissing`), sets `window.map` for the capture scripts |
| `style.json` | Generated by `tools/build-style.mjs` (87 layers). Committed so the style can be read without running anything. Its URLs point at `http://localhost:8787` |
| `fonts/` | Montserrat 400/500/600 normal + italic and 700 normal, latin subset woff2 from `@fontsource/montserrat` 5.2.5. SIL OFL 1.1 (`fonts/OFL.txt`) |
| `tools/build-style.mjs` | Builds `style.json`: Protomaps `light` flavour recoloured to cycle.travel, plus the cycling layers. **Start here** |
| `tools/shot.mjs` | `shot(hex)`: converts a colour sampled from a Chrome screenshot back to the sRGB value the page drew (see the style doc, "Colour sampling") |
| `tools/routes.mjs` | Overpass route relations → `data/routes.geojson`: one line per chain of ways with `network`, `rank`, `minz`, `ref` |
| `tools/shields.mjs` | Overpass route relations → `data/shields.geojson`: one chained line per signed relation with `badge`, `label`, `order`, `ev` |
| `tools/pois.mjs` | Overpass stations and hills → `data/pois.geojson` (`kind`: `station` / `peak`) |
| `tools/paths.mjs` | Overpass paths → `data/paths.geojson` with `c` (`p` paved, `u` unpaved, `f` footpath-only bridleway), `k` (knockout), `bridge` |
| `tools/serve.ts` | Bun static server on :8787, plus `/world.pmtiles`: a Range proxy to strava-stitch's Protomaps world file (below) |
| `tools/native-spike.mjs` | WS3.0 spike: cuts `style.json` down to the basemap layers for MapLibre Native in the app (glyph PBFs instead of `font-faces`, Ride On's R2 basemap) |
| `scripts/native-spike.sh` | WS3.0 spike: builds the Montserrat glyph PBFs (`cargo install build_pbf_glyphs`) and the spike style into `app/Packages/Features/Sources/RoutesUI/CycleMapSpike/` |
| `scripts/setup-vendor.sh` | Copies the MapLibre and PMTiles browser builds out of `node_modules` into `vendor/` |
| `scripts/fetch-osm.sh` | Downloads route relations, stations/hills and paths from Overpass into `raw/`, retrying while Overpass is at capacity |
| `scripts/build-data.sh` | `raw/` → `data/*.geojson` |
| `overpass/` | The Overpass QL behind `fetch-osm.sh`, plus `park.overpass` (every highway in Richmond Park, used to work out the path rule) and `paths-count.overpass` (size check) |
| `capture/` | Scripts for Chrome DevTools `evaluate_script`: `ct-prep.js` hides cycle.travel's sidebar and waits for tiles; `ml-prep.js` waits for the prototype |
| `analysis/` | Python measuring tools used to tune the style against cycle.travel screenshots (table below) |

`vendor/`, `node_modules/`, `raw/` and `data/` are gitignored.

## Run it

Needs Bun (≥1.4) and Node (≥22). From this directory:

```sh
bun install
bun run setup     # vendor/ from node_modules
bun run fetch     # raw/ from Overpass: ~160 MB, 15–45 min depending on how busy Overpass is
bun run data      # data/*.geojson
bun run style     # style.json (only needed after editing tools/build-style.mjs)
bun run serve     # http://localhost:8787
```

Open `http://localhost:8787/#13/51.4455/-0.2665` (MapLibre's hash is `#zoom/lat/lon`). After rebuilding
the style, reload with the cache disabled: the browser holds on to `style.json`.

Data covers south-east England: routes and paths in `50.70,-1.40 → 52.10,1.00`, London's `lcn` network in
`51.28,-0.55 → 51.70,0.30`. Outside that you get the basemap only.

**Basemap.** `serve.ts` proxies byte ranges to `https://stravastitch.com/maps/world-20260908.pmtiles`, the
Protomaps world build Dan already hosts on R2 for strava-stitch (137,855,359,979 bytes, z0–15). That
endpoint accepts single ranges of at most 8 MiB, which is what the PMTiles client asks for. Requests go out
with User-Agent `ride-on-map-prototype/0.1`. Don't point the app at this file; WS1 sets up Ride On's own.

**Overpass etiquette.** `fetch-osm.sh` sends User-Agent `ride-on-map-prototype/0.1` and backs off on 502/504.
The public mirrors (kumi, private.coffee, mail.ru, osm.jp) were all failing on 18 October 2026;
`overpass-api.de` worked with retries.

## Comparing against cycle.travel

The screenshots were taken with the Chrome DevTools MCP server. The method, so new ones line up:

1. `emulate` a 1200×800 viewport at device pixel ratio 2 (not `resize_page`).
2. cycle.travel: navigate to `https://cycle.travel/map?lat=<lat>&lon=<lon>&zoom=<ct zoom>`, run
   `capture/ct-prep.js` with `evaluate_script`, take the screenshot.
3. Prototype: navigate to `http://localhost:8787/#<ct zoom − 1>/<lat>/<lon>`, run `capture/ml-prep.js`,
   take the screenshot. Don't wait on `map.once('idle')` from `evaluate_script`: it hangs. The script polls
   `map.loaded() && map.areTilesLoaded()` instead.
4. `analysis/pair2.py ct.png ml.png out.jpg 350 1`. cycle.travel's map still lays out as if the sidebar
   were there, so its features sit 350 device px to the right of ours; the script crops that off.

**Zoom offset.** cycle.travel is Leaflet with 256 px tiles; MapLibre uses 512 px tiles. cycle.travel zoom
*n* is MapLibre zoom *n − 1*. Every zoom in the style doc is given in MapLibre zooms unless it says "ct".

The screenshots are only for comparison. Don't scrape or proxy cycle.travel's tiles or APIs (its tile
server returns 403 to non-browser clients, and that's their call).

## Analysis tools

Python 3.12+: `python3 -m venv analysis/.venv && analysis/.venv/bin/pip install -r analysis/requirements.txt`.
Run them with `-I` and paths as arguments. All measurements are in device pixels of a DPR 2 screenshot.

| Tool | Use |
|---|---|
| `pair.py`, `pair2.py` | Side-by-side comparison images |
| `crop.py` | The same crop from several images, upscaled, side by side |
| `sheet.py` | Contact sheet of labelled crops (uses macOS Helvetica) |
| `dots.py image colour` | Diameter and spacing of route dots of one colour |
| `dashes.py` | Length, width and spacing of brown unpaved dashes. Crashes if it finds fewer than two dashes |
| `badges.py`, `shield.py` | Find route badges and measure their box and colours |
| `ink.py` | Bounding box of dark text pixels, for label size and letter-spacing |
| `ct-classify.py`, `overlay.py` | For each OSM way in an Overpass dump, which cycle.travel line style is drawn under it; draw ways over a screenshot. How the path rule was worked out |
| `calib.py`, `calib2.py` + `cal.json` | Fit the screenshot colour transform behind `tools/shot.mjs` from a page of 80 known swatches |
| `near.py`, `sample.py`, `topcols.py` | Colour sampling helpers |
